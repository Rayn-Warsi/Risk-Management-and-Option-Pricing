# Risk Management & Option Pricing

Quantitative analysis of financial risk and option pricing implemented in R.

## Overview

This project applies statistical and financial modelling techniques to study risk and option-pricing problems. The analysis focuses on translating financial theory into reproducible quantitative calculations.

## Methods

- Financial risk analysis
- Option pricing
- Statistical analysis in R
- Quantitative interpretation of model outputs

## Repository

The main analysis is contained in the R script in this repository.
